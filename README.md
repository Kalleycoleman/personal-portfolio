# Kalley Coleman Portfolio

A responsive React/Vite portfolio built from the V3 Figma design library.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Routes

- `/` — combined Alt Home 1, 2, and 3 flow
- `/work` — Fraxes.AI case study
- `/about/work` — broader work, research, and lecturing stories

Contact, résumé, and additional project URLs are intentionally marked as pending until final links are supplied.
